# Deploy to GitHub Pages
1. Create a public GitHub repo.
2. Upload everything in this folder to the repo root: index.html, lessons.js, chapters.js, practice/, practice-files.zip, .gitignore.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open https://YOUR-USERNAME.github.io/REPO-NAME/
Never commit an API key. Keep all files next to index.html or lessons and chapters will not load.
