# Deploy to GitHub Pages
1. Create a public GitHub repo.
2. Upload everything in this folder to the repo root: index.html, lessons.js, chapters.js, quizzes.js, diagrams.js, practice/, practice-files.zip, TESTING.md, ALIGNMENT.md, .gitignore.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open https://YOUR-USERNAME.github.io/REPO-NAME/
Never commit an API key. Keep the .js files next to index.html or lessons, chapters, quizzes and diagrams will not load.
